# LobbyWatch
Browser extension that filters game lobbies and notifies when matching lobbies appear.

## Dev
* Use bun
* Use `bun run test` to run tests instead of `bun test`
* Use the dev-browser skill for manual verification

## UX Philosophy
* Minimal clicks to result
* Notifications are critical - must always appear and auto-dismiss

## Testing Philosophy
* E2E confidence over unit tests
* Realistic browser tests preferred

## Architecture Philosophy
* Simple > clever
* Avoid abstractions
